# Calculator

Консольный калькулятор поддерживает операции `+`, `-`, `*`, `/`, `^`, скобки и вызовы функций. При запуске приложение загружает плагины из папки `plugins`. Имя функции считывается из плагина и не зависит от имени файла библиотеки.

В комплект входят функции `sin(x)` (аргумент в градусах), `deg(x)` (перевод радиан в градусы) и `ln(x)` (натуральный логарифм). Ошибки выражений, некорректные плагины и исключения функций обрабатываются приложением; после ошибки можно вводить следующие выражения.

Примеры: `16 + 4 * (3 - 1)` даёт `24`; `2^4 + sin(90)` даёт `17`.
