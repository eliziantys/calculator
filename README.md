# Calculator

Консольный калькулятор на C++ с ядром для вычисления выражений и динамическими плагинами. Поддерживаются операции `+`, `-`, `*`, `/`, `^`, скобки, унарные знаки и вызовы функций.

При запуске программа анализирует библиотеки в папке `plugins`. Каждый плагин экспортирует точку входа `calculator_plugin_init`, которая сообщает ядру имя функции и указатель на неё. Имя DLL не используется для определения функции. Библиотеки удерживаются RAII-объектами и выгружаются при завершении программы.

Плагины: `sin(x)` — синус в градусах; `deg(x)` — перевод радиан в градусы; `ln(x)` — натуральный логарифм; `exp(x)` — экспонента. Некорректные библиотеки пропускаются, ошибки вычислений и исключения функций выводятся в консоль.

Сборка настраивается в `CMakeLists.txt`. Для запуска используйте собранную программу из каталога, рядом с которым находится папка `plugins`.

Примеры: `16 + 4 * (3 - 1)` даёт `24`; `2^4 + sin(90)` даёт `17`; `exp(1)` даёт приблизительно `2.718281828`.

## Демонстрация плагина

1. Запустите программу с библиотекой `funcexp` в папке `plugins` и вычислите `exp(1)`.
2. Временно переместите библиотеку `funcexp` из `plugins` в другое место и перезапустите программу. Вызов `exp(1)` будет отклонён как неизвестная функция.
3. Верните библиотеку в `plugins`, снова запустите программу и проверьте `exp(1)`. Пересобирать калькулятор при этом не требуется.

В Windows библиотека имеет расширение `.dll`, в macOS — `.dylib`, в Linux — `.so`.
